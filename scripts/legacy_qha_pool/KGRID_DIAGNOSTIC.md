## 0. 修正后的结论

1. **AlTa 的 E0 对 k 网格明显敏感**：最大与最小网格差 **4.39 meV/atom**；
   `k=5×5×5` 与当前最大网格差 **3.14 meV/atom**。
   **当前最大网格（k=15）尚未被更密网格验证，不能称为"已收敛值"。**
2. **`shift 0.5`（Gaussian 心）不改善**：跨度 2.32 meV/atom，与 Γ 心同量级。
3. **`8×8×8` 的 `mag = 0.1316` 已查清**：三个自旋起始态**能量简并（0.032 meV/atom）
   而磁矩从 0 变到 0.13 μB**。是**磁矩不唯一**，不是"另一个基态"。
   AlTa 取**非磁分支作为工作态**（但该差值 0.003–0.032 meV/atom **小于** k 网格误差，
   故不能称"自旋态已唯一确定"）。**且自旋歧义不能解释 k 振荡**（0.032 ≪ 1.94 meV/atom）。
4. **`ISMEAR=-5` 只适用于静态总能，不能作为声子/力的默认配方**（见 §4.3）。

**本报告不能支持的结论**（写了会误导）：

| 不可说 | 为什么 |
|---|---|
| "k=15 已收敛" | 它只是**本轮最大网格参照**，没有被更密网格验证 |
| "全池都需要 k≥11" | 只测了 BCC-Al-Ta 一个结构 |
| "AlTa 的自旋态已唯一确定" | 非磁与磁性分支的能量差（0.003–0.032 meV/atom）**小于 k 网格误差** |
| "软模导致了 E0 振荡" | 无因果证据；软模只在独立方法中复现过（见 §3.4） |

| | **能量跨度** | **0.0317 meV/atom** | |

### 3.2 结论（三条，都是负结果，但很重要）

**① `8×8×8` 的 `mag = 0.1316` 不是"另一个基态"。**
三个自旋起始态的能量跨度只有 **0.032 meV/atom（= 0.5 meV/cell）**，
而磁矩从 0 变到 0.13 μB。**能量几乎简并，磁矩不唯一。**

正确的说法是：**该网格下磁矩不是唯一确定的，但能量是稳健的。**

**② 自旋歧义不能解释 k 网格振荡。**
自旋跨度 0.032 meV/atom **远小于** k 网格跨度 1.94 meV/atom。
**k 网格的非单调性另有原因，与电子态选择无关。**（这否掉了我 v1 的猜测。）

**③ AlTa 取「非磁分支」作为工作态。** `ISPIN=2` 不给更低的能量，
`ISPIN=1` 与 `ISPIN=2` 差 0.003–0.032 meV/atom。

> **但这个差值远小于尚未解决的 k 网格误差（1.94 meV/atom）**，所以只能说
> **「非磁分支作为 AlTa 的默认计算状态」**，**不能说自旋态已被唯一确定**。
> 记录自旋检验结果即可；这不等于证明了该自旋态在所有网格、体积和声子计算中唯一。

### 3.3 但这条对 tb2j 有直接影响

既然**粗网格下磁矩不唯一**（0 → 0.13 μB，能量几乎不变），
那么 `BMAGN` / `TC` 这类**依赖磁矩的**量在粗网格上是**不可定义的**。

**→ 对磁性端基（池内含 Cr 的 28 个 BCC 端基），k 网格必须密到能把磁矩定住，
而这与 QHA 对能量的要求是两个不同的判据。**

### 3.4 与软模的关系：**不得归因**

有限 q 软模与"费米面附近电子结构影响 E0 的积分敏感性"可能有联系，
但**现有证据没有证明因果**。把 k 振荡归给软模，会把一个尚未查清的数值问题
写成物理解释。软模目前只在独立方法中复现过（E1 / D0-A），
**电子态与软模之间的耦合尚未测试。**

## 4. 三条设计决定（评审指出的）

### 4.1 不冻结"全池都必须用 k≥11"

本次只测了 BCC-Al-Ta 一个结构。应推动一次**受控校准**，而不是直接给全池定网格。

### 4.2 不冻结全局 `ISMEAR=-5`

**这是最重要的一条。** 这批 `ISMEAR=-5` 的 OUTCAR 自己会给出警告：
四面体法不考虑费米占据的变化，**金属的力和应力可能不准确**。
VASP 建议金属弛豫与声子力用合适的展宽方法，并把熵项控制在约 1 meV/atom 内。

关键区分：

| 用途 | 展宽选择 |
|---|---|
| 高精度**静态总能** | `ISMEAR=-5` 合适 |
| **金属的力 / 力常数 / 声子** | 需要展宽方法，`-5` 不一定合适 |

**`ISMEAR=-5` 输出 `T*S=0` 是数值积分方法的属性，不代表真实有限温度电子熵为零。**
MP 的负熵也不应直接读成"物理熵错误"——应看它的**量级、各体积间是否一致、
以及能量/力/声子是否收敛**，而不是要求它必须为正。

**→ v1 说"`ISMEAR=-5` 可以冻结"是过头的，已撤回。** 它只对静态总能成立。

### 4.3 atomate2 的 ISMEAR fallback（v1 描述有误）

v1 说"atomate2 会把 `ISMEAR=-5` 静默换成 0"。**核对 pymatgen 源码后，这个说法不准确**：

```python
# pymatgen/io/vasp/sets.py:752
if kpoints is not None and np.prod(kpoints.kpts) < 4 and incar.get("ISMEAR", 0) == -5:
    incar["ISMEAR"] = 0
```

**触发条件是 k 点乘积 < 4**，即只有 1×1×1（或 2×1×1 之类）才会触发：

| 胞 | atomate2 默认网格 | 乘积 | 触发？ |
|---|---|---|---|
| 2 原子 | 7×7×7 | 343 | 否 |
| 16 原子 | 3×3×3 | 27 | 否 |
| 54 原子 | 2×2×2 | 8 | 否 |
| **128 原子** | **1×1×1** | **1** | **是** |

所以**这条不是当前流水线的已证缺陷**。另外实测确认：

```
RelaxSetGenerator  → ISMEAR=0   （它自己的默认，不是 fallback）
StaticSetGenerator → ISMEAR=-5
```

`main_qha.py` 也显式设置 `ISMEAR=1`。**应以实际生成的 INCAR/KPOINTS 为准，
不要从模板默认值推断。**
