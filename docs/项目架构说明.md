# HT-VASP 项目架构说明

## 项目概述

HT-VASP 是基于 atomate2 的 VASP 计算自动化框架，提供磁性交换相互作用 (OstravaJ)、准谐近似 (QHA) 等计算工作流。

## 目录结构

```
ht-vasp/
├── htvasp/                    # 主包
│   ├── oj/                   # OstravaJ 磁性交换模块
│   │   ├── __init__.py       # 模块入口
│   │   ├── input_set.py     # VASP 输入生成
│   │   ├── jobs.py          # @job 任务函数
│   │   ├── maker.py         # Flow Maker
│   │   └── task_doc.py      # 输出模型
│   ├── workflows/           # 工作流接口
│   │   ├── base.py         # Worker 基类
│   │   ├── oj.py          # OJWorker
│   │   ├── static.py      # StaticWorker
│   │   ├── relax.py      # RelaxWorker
│   │   └── qha.py       # QHAWorker
│   ├── utils/             # 工具函数
│   ├── model/            # 数据模型
│   └── slurm/           # Slurm 管理
├── docs/                    # 文档
├── tests/                   # 测试
├── ostravaj/               # OstravaJ 外部脚本
├── scripts/                # 辅助脚本
└── configs/               # 配置文件
```

## 核心模块功能

### htvasp/oj

磁性交换相互作用计算。

| 文件 | 功能 |
|------|------|
| `input_set.py` | OJInputSetGenerator 继承 VaspInputGenerator，生成 VASP 输入文件和 OJ.conf |
| `jobs.py` | oj_generate, create_flip_jobs, oj_solve 三个 @job 函数 |
| `maker.py` | OJMaker (组合 Jobs 生成 Flow), FlipMaker (单 flip VASP 执行) |
| `task_doc.py` | OJResult 模型 (含 J 参数、Tc、磁矩等信息) |

### htvasp/workflows

用户接口层，封装 Worker 类。

| 文件 | 功能 |
|------|------|
| `base.py` | Worker 基类，Flow 执行、续算、结果获取 |
| `oj.py` | OJWorker，默认使用 OJMaker |
| `static.py` | StaticWorker，静态计算 |
| `relax.py` | RelaxWorker，结构弛豫 |
| `qha.py` | QHAWorker，准谐近似 |

### htvasp/utils

运行工具。

| 文件 | 功能 |
|------|------|
| `local.py` | 本地执行 Flow (含 resume 支持) |

### htvasp/model

数据模型。

| 文件 | 功能 |
|------|------|
| `endmember.py` | 端基模型定义 |

## 模块依赖关系

```
OjWorker (workflows/oj.py)
    └─> OJMaker (oj/maker.py)
        ├─> oj_generate (oj/jobs.py)
        │   └─> OJInputSetGenerator (oj/input_set.py)
        ├─> create_flip_jobs (oj/jobs.py)
        │   └─> FlipMaker (oj/maker.py)
        └─> oj_solve (oj/jobs.py)
            └─> OJResult (oj/task_doc.py)
```

## 执行流程 (OJ)

1. User → OJWorker.run_flow()
2. OJWorker → OJMaker.make()
3. OJMaker.make() 生成 Flow:
   - job1: oj_generate → 生成 flip* 目录
   - job2: create_flip_jobs → 动态创建 FlipMaker jobs
   - job3: oj_solve → 解析结果
4. Flow → run_locally() 执行
5. 结果 → OJResult

## 关键代码文件速览

| 文件 | 关键类/函数 | 一句话功能 |
|------|------------|---------|
| `oj/input_set.py` | OJInputSetGenerator | 继承 VaspInputGenerator，生成 OJ 输入 |
| `oj/jobs.py` | oj_generate, create_flip_jobs, oj_solve | @job 装饰的三个步骤函数 |
| `oj/maker.py` | OJMaker, FlipMaker | 生成完整 Flow / 单 flip VASP 执行 |
| `oj/task_doc.py` | OJResult | 结果模型，含 J、Tc、磁矩等 |
| `workflows/base.py` | Worker | 基类，执行 Flow、续算、结果获取 |
| `workflows/oj.py` | OJWorker | 用户入口 |
| `utils/local.py` | run_locally_custom | 本地执行 (支持 resume) |
| `slurm/manager.py` | SlurmManager | Slurm 作业提交 |

## 数据流

```
Structure (POSCAR)
    ↓
OJInputSetGenerator.get_input_set()
    ↓
write_oj_input_set() → POSCAR, INCAR, POTCAR, KPOINTS, OJ.conf
    ↓
ostravaj.sh generate → flip000, flip001, ...
    ↓
FlipMaker (atomate2) → vasprun.xml
    ↓
ostravaj.sh solve → OJ_solution.json
    ↓
OJResult.from_solution()
    ↓
{ J_reprs, Js, Tc_MFA, Tc_RPA, ... }
```
