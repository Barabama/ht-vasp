# TB2J 与 SQS 数据审计：与 DFPT-QHA 规范的一致性

日期：2026-10-25
范围：`data/endmembers/*/*-tb2j.json`（44 个）+ `data/sqs_mixing/`（3 个体系）
参照规范：`htvasp/dfpt_qha/input_set.py` 的 `SHARED_INCAR`，以及实际归档的 INCAR
结论：**两层都不能直接进 TDB。** TB2J 对池子的磁性物理是空的；
SQS 只有 1 个二元体系，且它的几何不是它所报能量那个能量面的极小点。

---

## 0. 三层的现状

| 层 | 数据 | 能进 TDB？ |
|---|---|---|
| QHA 端基 | 51/84（BCC 27/28、FCC 17/49、SER 7/7） | 基本可以 |
| **SQS 混合** | **3/21 个 BCC 二元（Al-Nb、Al-Ti、Nb-Ti），每个 3 个成分** | **不能** |
| **TB2J 磁性** | **44 个 run，池内 9 个，Cr/Hf/Ta/Zr 覆盖为 0** | **不能** |

一个二元 TDB 需要四样东西：纯元素在各晶格的 G(T)（QHA 端基）、有序端基的 G(T)
（QHA 端基）、中间成分的 L 参数（SQS 静态）、磁性相的 TC/BMAGN（TB2J）。
**第三和第四样现在都没有。**

## 0bis. 一条结构性的前提：TB2J/SQS 根本不在端基树里

```text
find data/endpoints data/remote -iname '*tb2j*' -o -iname '*sqs*'   → 0 hits
```

**44 个 TB2J JSON 和全部 SQS 数据都在旧的 `data/endmembers/` 树里**，
那是为 8 元素（Al Nb Ti V Co Fe Mn Ni）建的。DFPT-QHA 用的
`data/endpoints/` 与 `data/remote/B5070/data/endpoints/` 里一个都没有。

所以"池内 9/84 个端基有 TB2J"这个数是**从另一棵树继承来的上限**：
那 9 个名字恰好也在池里，但它们的胞、设置和生成流程都是为旧元素集服务的。
**按端基树算，池的 TB2J 覆盖是 0/84。**

这一点决定了 §1 的每一条：不是"覆盖不全"，是"没有接上"。

**另外有 5 棵 `data/endmembers*` 树，各自 44 个 TB2J JSON。**
对 `data/**/*-tb2j.json` 做递归 glob 会数出 220 个文件，**重复 5 倍**：

| 树 | 与 live 逐字节相同 | 说明 |
|---|---:|---|
| `data/endmembers` | — | live |
| `-v1-backup-20260908` | 0/44 | **旧契约代**：无 `magnetic_observables`、无 `magnetic_contract`、无 `cell` |
| `-v2` | 32/44 | |
| `-v2-fixed-20260908` | 44/44 | live 的副本 |
| `-v2-preorder-backup-20260908` | 32/44 | |

任何按递归 glob 汇总 BMAGN 的脚本都会**把两代契约混在一起**。

## 1. TB2J：池子的磁性物理完全没有数据

### 1.1 覆盖

| 家族 | 有 TB2J | 总数 | 缺 |
|---|---:|---:|---:|
| BCC/B2 | 6 | 28 | 22 |
| FCC/L1₂ | **0** | 49 | 49 |
| SER | 3 | 7 | 4 |
| **合计** | **9** | **84** | **75** |

44 个 TB2J 文件里 **35 个完全在池外**（Co/Fe/Mn/Ni/V）。
元素槽位统计：Al 6、Nb 6、Ti 6、**Cr 0、Hf 0、Ta 0、Zr 0**。

池子标记了 15 个磁性端基（`magnetic_policy = confirmed_branch`），
**全部含 Cr**。TB2J 对 Cr 的覆盖是 **0**。
所以：**这 15 个端基一个 TC 都拿不到。**

### 1.2 池内 9 个端基的实际数值

| 端基 | contract_status | TC (K) | BMAGN (μB) | max\|m\| |
|---|---|---:|---:|---:|
| BCC-Al-Al | nonmagnetic | — | 0.00000 | 0.0000 |
| BCC-Al-Nb | nonmagnetic | — | 0.00020 | 0.0003 |
| BCC-Al-Ti | nonmagnetic | — | 0.00015 | 0.0003 |
| BCC-Nb-Nb | computed | **1.436** | 0.00730 | 0.0073 |
| BCC-Nb-Ti | unsupported | null | 0.00245 | 0.0031 |
| BCC-Ti-Ti | computed | **33.831** | 0.01965 | 0.0198 |
| SER-Al | not_applicable | — | 0.00010 | 0.0001 |
| SER-Nb | not_applicable | — | 0.00010 | 0.0001 |
| SER-Ti | not_applicable | — | 0.00055 | 0.0006 |

**只有 2 个有 TC，而这两个的磁矩是 0.007 和 0.020 μB** —— 比真实过渡金属
（1–3 μB）小两个量级。J 的量级也印证：

| 端基 | max\|J_iso\| (meV) | 折合 k_B·T(300 K) | 对照：BCC-Co-Fe |
|---|---:|---:|---:|
| BCC-Nb-Nb | 0.0347 | 0.0013 | 23.33 meV（0.90） |
| BCC-Ti-Ti | 0.7332 | 0.028 | 23.33 meV（0.90） |

而且 TB2J 的 `sum(w_magmom)` 与同一目录下 VASP 的总磁矩对不上：
Nb 差 **−716 倍**，Ti 差 7.7 倍。这是 Wannier 噪声，不是磁矩。

**MFA 公式用的是单位自旋**（`spin_normalization: "unit"`）。
把真实磁矩代进去（TC ∝ S(S+1)，S = m/2）：

```text
BCC-Nb-Nb:  1.436 K → 0.0026 K   （高估 546 倍）
BCC-Ti-Ti: 33.831 K → 0.168 K    （高估 202 倍）
```

结论：**池内没有任何一个可用的 TC/BMAGN。** 把 1.44 K 写进
`PARAMETER TC(...)` 会在 1.4 K 造一个实验看不见的相变，而且很难被发现。

### 1.3 结构层面的问题

**(a) `structure` 是未弛豫的模板，不是算 J 用的胞。**
44 个文件里 42 个 `structure.lattice` ≠ `cell`。以 BCC-Nb-Nb 为例：

```text
cell      (J 实际算在):  a = 3.30310 Å
structure (记录里写的):  a = 2.85971 Å   ← 差 13.4%
```

`structure` 是 `endmember.py` 的 B2 模板胞。下游若用 `structure` 取几何，
会拿到一个 13% 错误的晶格常数。em-tdb-v2 的 `read_tb2j_json` 正是读 `structure`。

**(b) 位点标签的两个块不是同一个原子顺序。**
把 `atom_moments[*].xyz` 用 `cell` 的逆矩阵换成分数坐标，再与
`structure.sites[*].abc` 比较：44 个文件里 **14 个不一致**，
而且**全部是同核胞**（`BCC-X-X`、`FCC-X-X`、SER-Co/Fe/V）。
异核胞的分数坐标是一致的。

| | 一致 | 不一致 |
|---|---:|---:|
| 分数坐标比较 | 30 | 14（全是同核胞） |
| 笛卡尔坐标比较 | 8 | 36（`structure` 用的是模板胞，直接比没有意义） |

同核胞里互换本来无害，**前提是磁矩相等**。检查结果：

```text
BCC-Nb-Nb   [-0.0073, -0.0073]  相等 → 互换无害
SER-V       [ 0.0003]           单原子 → 无关
BCC-Ti-Ti   [-0.0198, -0.0195]  不等 → 互换会改 0.0003 μB
SER-Fe      [ 2.2081,  2.2084]  不等 → 互换会改 0.0003 μB
FCC-Fe-Fe   [2.5713, 2.5714, ...] 不等 → 同量级
```

目前偏差都 ≤ 0.0004 μB，可以忽略。但这说明两个块是**独立生成**的，
原子顺序不保证一致 —— 换成 AFM 胞（磁矩 ±1.1）就会变成符号错误。
`main_w90.py` 生成这两块时应当共用一个位点顺序。

**(c) `calphad.production_ready` 与 `audit.production_ready` 对 9/44 个文件矛盾。**

| 端基 | audit | calphad | status |
|---|---|---|---|
| BCC-Nb-Ti | False | **True** | unsupported |
| SER-*（8 个） | True | **False** | not_applicable |

只看 `calphad.production_ready` 的消费者会给 BCC-Nb-Ti 写一个没有 TC 的
磁性参数块。

**(d) BCC-Nb-Ti 的 `unsupported` 不是"缺输入"。**
`exchange_matrix = [[0.001, 0], [0, 0]]`，最大本征向量是 `[1, 0]`。
代码的符号判据遇到 0 分量返回 None（`_transition_from_vector`），
于是记为 "largest-eigenvalue vector has no uniform sign pattern"。
物理上这是"只有一个子晶格有耦合"。拒给 TC 是对的，但措辞误导。

### 1.4 em-tdb-v2 能读，但读的是错的那部分

实测（`em-tdb-v2/src/emtdb_v2/magnetic/readers.py`）：

```python
read_tb2j_json(".../BCC-Nb-Nb-tb2j.json")
# → MagneticExchangeDataset, 2914 j_pairs, BMAGN 0.0073, TC 1.4359
```

**能读**。它读 `structure` / `j_pairs` / `atom_moments`，然后自己重算
BMAGN 和 TC —— 重算结果与 ht-vasp 存的 `magnetic_observables` 完全一致。
所以"两个生产/消费方字段名不一致"这一条**不成立**：em-tdb-v2 根本不需要
`magnetic_observables`。

但它重算出来的 TC 与 ht-vasp 存的是**同一个数**，因此带着同一个问题
（单位自旋 + 非磁基态）。**一致不等于正确。**

## 2. SQS：只有 1 个二元，而且几何不对

### 2.1 覆盖与完成度

SQS 数据在**两代**里，而且第一代（`data/endmembers/*/*-sqs.json`，
2026-09-04）比 `data/sqs_mixing/`（2026-08-21）**更完整**：

| 体系 | 完成 | 位置 |
|---|---|---|
| **BCC-Al-Nb** | **3/3 点，all_static_successful** | `data/endmembers/`（09-04）+ `data/sqs_mixing/`（08-21，重复实现） |
| **BCC-Al-Ti** | **3/3 点，all_static_successful** | `data/endmembers/`（09-04）；`data/sqs_mixing/` 的 0/3 是**另一次失败的重跑** |
| **BCC-Nb-Ti** | **3/3 点，all_static_successful** | `data/endmembers/`（09-04） |
| BCC-Al-V / Nb-V / Ti-V | 3/3 点 | 池外 |
| BCC-Al-Nb-v2 | 0/3 | 全 pending；端点 BCC-Al 失败 |

所以：**21 个 BCC 二元里 3 个有完整 SQS**（Al-Nb、Al-Ti、Nb-Ti）。
21 个 FCC 二元里 **0 个**。

三代设置相同（`ENCUT 400 relax / 520 static`），所以下面 §2.3 的几何问题
**三个体系全都有**。

### 2.2 混合焓（BCC-Al-Nb，以 SQS 自己的参考为基准）

| x_Al | E/atom (eV) | ΔH_mix (meV/atom) | ΔH_mix (J/mol) | 点值 L0 (J/mol) |
|---:|---:|---:|---:|---:|
| 0.25 | −8.700488 | −110.07 | −10620 | −56639 |
| 0.50 | −7.187042 | −249.07 | −24032 | −96127 |
| 0.75 | −5.533641 | −248.12 | −23940 | −127681 |

三个点值 L0 相差 **2.25 倍**。ATAT 拟合出单个 L0 = −94043 J/mol，
残差 58–72 meV/atom。**这是模型形式（单 L0 不够）造成的，不是数据不一致**——
加 L1 后残差降到 5.44 meV/atom。

### 2.2bis 同一成分的两次 SQS 实现差 32 meV/atom

BCC-Al-Nb 有两套独立的 SQS 实现（09-04 与 08-21），设置完全相同：

| x_Al | 09-04 ΔH (meV/atom) | 08-21 ΔH (meV/atom) | 差 |
|---:|---:|---:|---:|
| 0.25 | −110.34 | −110.07 | +0.27 |
| **0.50** | **−217.01** | **−249.07** | **−32.07** |
| 0.75 | −248.41 | −248.12 | +0.28 |

x=0.25 和 0.75 一致到 0.3 meV/atom，说明不是全局偏移，而是 **x=0.5 的
实现散差**。用 09-04 那套重拟合单 L0：

```text
09-04: L0 = −88278 J/mol, 残差 [61.2, 11.7, −76.9] meV/atom
08-21: L0 = −94043 J/mol, 残差 [72.0, −5.4, −64.7] meV/atom
```

**L0 移动 5.8 kJ/mol，只因为换了同一成分的另一种 SQS 实现。**
ATAT 对照用的 71.97 残差是 08-21 那套的；换一套就变成 76.9。
**一个 SQS/成分不足以把 L0 定到 5 meV/atom。**

### 2.3 几何：弛豫用的能量面不是报能量那个

**这是最严重的一条。** SQS 的 relax 用 ENCUT 400，static 用 ENCUT 520。
两者不是同一个能量面，所以 ENCUT-400 的极小点在 ENCUT-520 上有残余力：

| 点 | relax 末 max\|F\| (eV/Å) | static max\|F\| (eV/Å) | static 对角应力 (kBar) |
|---|---:|---:|---|
| Al 参考 | 0.0000 | 0.0000 | −11.0 |
| Nb 参考 | 0.0000 | 0.0000 | −0.5 |
| x0.25 | 0.0468 | 0.0852 | +12.1 / +12.4 / +8.4 |
| **x0.5** | **0.0389** | **0.5851** | **−15.8 / +8.1 / +9.2** |
| x0.75 | 0.0354 | 0.0324 | −7.5 / +3.5 / +2.0 |

x0.5 的残余力从 0.039 跳到 **0.585 eV/Å（15 倍）**。
按 k ≈ 10 eV/Å² 估，这部分几何误差约 **17 meV/atom** —— 与 ATAT 的
71.97 meV/atom 残差同量级。

**并且 x0.5 弛豫成了一个三斜胞：**

```text
x0.25  Pma2  a/b/c = 6.644 / 6.820 / 6.179   V/atom 17.497
x0.50  P1    7.995 / 5.840 / 5.832            V/atom 17.018  (a/b = 1.37)
x0.75  Pma2  7.802 / 5.880 / 5.779            V/atom 16.569
```

起始胞是立方 5.7194 Å 的 2×2×2 bcc 超胞。50/50 的无序 bcc 固溶体
**不应该**把 a/b 拉成 1.37。体积是对的（17.02，介于 16.57 和 17.50 之间），
**形状坏了**。在 3×4×4 Γ 心网格上，这类形状失稳无法与真实效应区分。

### 2.4 参考能量与 QHA 层对不上

| 元素 | SQS E/atom | DFPT-QHA E0/atom | 差 (meV/atom) |
|---|---:|---:|---:|
| Al | −3.633068 | −3.646808 | **+13.74** |
| Nb | −10.242871 | −10.225499 | **−17.37** |

分解（把 DFPT 的 E(V) 内插到 SQS 的体积）：

```text
Al: 几何贡献  −0.47 meV   |  其余（k 网格/LREAL/PREC）  +14.13 meV
Nb: 几何贡献  +2.31 meV   |  其余                        −20.02 meV
```

**所以偏移几乎全部来自静态设置，不是几何。** 静态的差异有：

| 设置 | SQS static | DFPT-QHA | 影响 |
|---|---|---|---|
| k 网格 | Γ 3×3×3 ~ 3×4×4 | MP 8×8×8 shift 0.5 | **18.9 倍** |
| LREAL | Auto → **实际 T（实空间）** | False → F | Pulay 型误差 5–20 meV/atom |
| LASPH | True | 未设（F） | 增广修正 |
| LMAXMIX | 4 | 未设（2） | 混合，非能量 |
| ENAUG | 1360 | 未设（291–483） | 增广修正 |
| PREC | Accurate | Normal | 经由 ENAUG/网格 |
| ISYM | 0 | 2 | 电荷对称 |

**LREAL 是最可疑的一条。** OUTCAR 里的实际取值：

```text
SQS  static : LREAL = Auto  ->  LREAL = T   real-space projection
DFPT phonon : LREAL = False ->  LREAL = F   real-space projection
```

VASP 把 16 原子 8 Å 的胞判成实空间投影。这个误差不随 ENCUT 收敛，
文献量级 5–20 meV/atom —— 与实测的 +14.13 / −20.02 meV/atom 同量级。
**但这是"同量级"的推断，不是已证实的归因**：LASPH、ENAUG、k 网格三者
也在同一批能量里。要分离必须做一次对照计算（同一几何，逐个改一个设置）。

这个偏移会进入 TDB：ATAT 树的端基能量**也**取自 SQS 层
（`static_source = sqs-static`），所以拟合内部自洽，但**端基能量与
QHA 层（func）描述的不是同一个相**。ATAT 把差额吸收进 ABIN。

### 2.5 三条次要但真实的问题

**(a) 同一个 ΔH 里的参考和合金点用了不同 k 网格。**

| 点 | 静态 k 网格 | NKPTS |
|---|---|---:|
| Al 参考 | Γ 3×3×3 | 14 |
| Nb 参考 | Γ 3×3×3 | 14 |
| x0.25 | Γ 3×3×4 | 19 |
| x0.5 | Γ 3×4×4 | 26 |
| x0.75 | Γ 3×4×4 | 26 |

网格由 pymatgen 的 `automatic_density` 按胞长生成，五个胞长不同（6.48–8.00 Å），
所以每个点拿到不同的网格。**每个 ΔH 都是两组不同网格的能量相减**，
网格误差不会抵消。另外 relax 一律用 Γ 4×4×4（比静态密），
所以几何优化用的网格和报能量用的网格也不是同一个。

**(b) SQS 生成记录无法复现结构。**
`structures/x0.25.generation.json` 里：

```text
config.composition      = {Al: 4, Nb: 12}
config.structure.species = 16 × "Al"     ← 模板，不是生成结果
seed = 0, seed_applied = False
```

记录的是 sqsgenerator 的**输入**（纯 Al 模板 + 成分约束），不是输出结构；
而且 `seed_applied: false`，附注说 sqsgenerator 没有可用的 seed 参数。
**v1 和 v2 的 SQS 实现都无法从记录里复现。**

**(c) SQS 起点比终态密 42–54%。**
模板是 a = 5.71942 Å 的 2×2×2 bcc 超胞（= 2 × 2.8597 Å，B2 Al-Ni 模板），
V/atom = 11.69；弛豫后：

| 点 | 终态 V/atom | 相对起点 |
|---|---:|---:|
| Al | 17.00 | **+45.4%** |
| Nb | 17.99 | **+53.8%** |
| x0.25 | 17.50 | +49.6% |
| x0.5 | 17.02 | +45.5% |
| x0.75 | 16.57 | +41.7% |

`ISIF=3` 从这么远的起点出发，路径依赖性很强。这直接来自 B2 模板的晶格常数
（2.8597 Å 是 Al-Ni 的值，既不是 bcc Al 的 3.2346，也不是 bcc Nb 的 3.3097）。

### 2.6 修法没有便宜的

上面每一条都是**输入**，所以都需要重跑：

- 只改静态（保留 ENCUT-400 几何）：LREAL / LASPH / ENAUG / k 网格都能修，
  但留下 0.5–2.3 meV/atom 的几何偏差和 x0.5 的三斜形状。
- 全重跑（relax + static）才能全清。

成本（实测 CPU 秒，16 原子）：

| 点类型 | relax | static | 合计 |
|---|---:|---:|---:|
| 参考（纯元素） | 163–1001 s | 85–493 s | 871 s 平均 |
| 合金点 | 2302–3306 s | 430–564 s | 3152 s 平均 |

规范化的 k 网格让 static 贵 18.9 倍、relax 贵 8 倍，所以：
**合金点约 3 倍（~2.6 h），参考点约 2 倍（~0.5 h）**。

整个 BCC 二元集：7 个参考（跨二元共享）+ 21×3 个合金点 = 70 点
→ **70–170 CPU 小时**，两节点串行 1.5–3.5 天。
FCC 还要另一套（L1₂ 4 原子 → 32 原子 SQS 超胞，单点约 4 倍）。

## 3. DFPT-QHA 的磁性：能免费捞出来，但不是干净的 BMAGN

DFPT-QHA 的 analysis JSON / `-vt` JSON / `DfptTaskDoc` **没有任何磁性字段**
（扫了 107 个 JSON，唯一命中是 `n_mesh_imaginary_modes`）。
但每个 run 都归档了 `1-EOS_equilibrium_relaxation/OUTCAR.gz`，
它的最后一个 `magnetization (x)` 块就是收敛后的逐位点磁矩。

`scripts/extract_magnetic_state.py` 把它读出来，写
`data/endpoints/<name>/magnetic-state.json`（带源文件 SHA-256）。
8/15 个磁性端基可读：

| 端基 | 类型 | net (μB) | mean\|m\| (μB) | 配方预期 |
|---|---|---:|---:|---|
| BCC-Al-Cr-2 | FM | +2.494 | 1.288 | 磁性 ✓ |
| BCC-Cr-Cr-2 | **AFM** | 0.000 | 1.134 | 磁性 ✓ |
| SER-Cr-1 | **AFM** | 0.000 | 1.134 | 磁性 ✓ |
| BCC-Cr-Zr-2 | FM | +1.685 | 1.039 | 磁性 ✓ |
| BCC-Cr-Hf-2 | FM | +1.700 | 0.941 | 磁性 ✓ |

### 3.1 三个必须记录的限制

**(a) 磁矩随体积强烈变化。** 以 BCC-Cr-Cr-2（AFM）为例：

| V (Å³/atom) | \|m\| (μB) |
|---:|---:|
| 10.146 | **0.000**（塌缩） |
| 10.800 | 0.232 |
| 11.482 | 0.925 |
| 11.833 (V0) | 1.334 |
| 12.192 | 1.714 |
| 12.931 | 2.060 |

最压缩的体积上**磁性完全塌缩**。所以这一条端基的 F(V,T) 混合了两种磁态。
单个 BMAGN 无法表示这件事 —— 只能记录，不能平均。

**(b) `FCC-Al-Cr-4` 从 10 μB 塌到 0。** 但它**不能**因此判为"跑错了"：
它弛豫到 V0 = 12.43 Å³/atom，而报告 §8.0a(j) 测到 22.96 meV/atom
磁性分支时用的是**未弛豫**的模板体积 13.03。两者不是同一个胞，比较无意义。
归档的这个 run 比 Stage-0A 的"Cr=3.0 分支"低 96 meV/atom —— 差值来自设置，
不是磁态。**结论只能是"该端基的磁态未定"，要在这个弛豫体积上重测才能定。**

**(c) AFM 端基的两个位点磁矩相等、符号相反**，所以
`mean|m| = 1.134` 而 `net = 0`。IHJ 约定是
`PARAMETER BMAGN` 取模长、`TC` 取负号表示 Néel —— 这两个端基正好用得上。

## 4. 结论与建议顺序

1. **现在能建的 TDB：没有。** QHA 端基够了（BCC 20/21 二元），但 SQS 只有
   1 个二元，TB2J 对 Cr 覆盖为 0。
2. **下一步优先级**（都不受端基队列阻塞）：
   - **SQS 重跑，先只做 BCC-Al-Nb**（5 个点，~13 CPU 小时）：
     ENCUT 520 relax、MP 8×8×8 shift 0.5 static、`LREAL=False`、`LASPH=False`、
     `ENAUG` 默认。这是唯一能把 L 参数做对的路径，也是验证修法的最小样本。
     **同一成分至少要 2 个 SQS 实现**（§2.2bis 的 32 meV/atom 散差说明
     单实现定不住 L0），所以 5 个点要变成 8 个点（2 参考 + 3×2 合金）。
   - **TB2J 先在 1 个 Cr 端基上打通**（BCC-Cr-Cr-2 或 BCC-Al-Cr-2）：
     这是全仓第一次在含 Cr 的胞上跑 W90/TB2J，`NUM_WANN`（2 原子 18、
     4 原子 36）、disentanglement 窗口、AFM 起始图案都未验证。
     打通后 15 个磁性端基合计约 5 CPU 小时。
   - 两者都通了，再按二元逐个铺开。
3. **不要**把现有 TB2J 的 TC 写进任何 TDB。1.44 K 和 33.83 K 是
   0.007 / 0.020 μB 胞上的单位自旋 MFA 数，物理上等于零。
4. **不要**把 SQS 现有几何当 ENCUT-520 的极小点用。x0.5 的 0.585 eV/Å
   残余力就是反证。
